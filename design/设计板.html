参考项目做「两千年的舆图长卷」，我们做「七十三年的势力沙盘 + 人物档案」。不在广度上比，在深度与叙事上另开一桌。

梁唐晋汉周
朱批

方向 A 史册朱批 DOCUMENT

浅米纸、墨字、朱红眉批。像一本带地图的史书，适合列传与章回阅读。缺点是仍带纸感，和参考项目的宣纸气质有重叠。

后唐 · 同光

方向 B 墨色沙盘 WAR ROOM ★

炭黑底、等高线、朱砂势力与箭头。第一眼就和「暖宣纸」区分开，像军帐推演；疆域、战争、政变成为舞台中心。

方向 C 关系星图 CONSTELLATION

人物为星、关系为弧、政权为星团。我们独有的 331 条关系天然适配；但单独做会脱离「地图」，适合作为第二主视图。

推荐组合：B 作壳 + C 作核 + A 作局部

默认进入「年份舞台」：墨色沙盘 + 一年一屏；点人进入星图列传；读章回切浅色史册模式。

为什么这样分

  • B 作壳：第一眼反差——它暖纸、我们墨沙；它地形、我们等高线。
  • C 作核：331 条关系是它没有的资产，星图能形成记忆点。
  • A 作局部：长文阅读时切浅色，兼顾章回与列传。

明确不做

  • 不做 2400 年通史、不做 CHGIS 州府边界竞赛
  • 不做诗词路线、寻址游戏、多语言（第一期）
  • 不复制书稿原文，只做年表与自拟摘要

验收标准

  • 随机年份 / 政权 / 人物 → 3 次点击内看到「发生了什么、谁参与、结局如何」。
